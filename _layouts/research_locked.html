--- layout: default --- {%- comment -%} Password gate for research entries — the generalization of the poem page's scheme (see bin/research_lock.py). The page ships only AES-GCM ciphertext (page.enc_payload under assets/enc/); the body decrypts in-browser via WebCrypto. One shared password unlocks every entry: on success it is kept in sessionStorage and other locked entries auto-open for the rest of the tab session. Plaintext never exists in this public repo. Presentation lives in _includes/research_styles.liquid (the .rzine "zine card" treatment). Both the lock and the decrypted body render inside the same card, so unlocking swaps the contents rather than repainting the page. {%- endcomment -%} {% include research_styles.liquid %}
